# Agentic Workflow — Standard Guide for the Team

This document standardizes how we use the **Democratize Quality** MCP (Model Context Protocol) server for API test planning, generation, and healing in this repo.

---

## 1. MCP Server: `@democratize-quality/mcp-server`

We use the [@democratize-quality/mcp-server](https://www.npmjs.com/package/@democratize-quality/mcp-server) npm package so Cursor (or other MCP clients) can call API planning, test generation, and test healing tools.

- **Package**: `@democratize-quality/mcp-server`
- **Docs / options**: See [npm package page](https://www.npmjs.com/package/@democratize-quality/mcp-server) for latest usage, CLI flags (e.g. `--agents`), and env vars.

---

## 2. Configuration

### 2.1 MCP config (`.vscode/mcp.json`)

MCP servers are configured in **`.vscode/mcp.json`** (workspace-level). This is the canonical setup for this repo.

**Snippet to use in this project:**

```json
{
  "inputs": [],
  "servers": {
    "democratize-quality": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "@democratize-quality/mcp-server@latest"
      ],
      "cwd": "${workspaceFolder}",
      "env": {
        "OUTPUT_DIR": "./api-test-reports"
      }
    }
  }
}
```

- **`command`**: `npx` runs the package without a global install.
- **`args`**: Package name; add any **CLI flags** here (e.g. `--agents` if supported by the package). Check the [npm package](https://www.npmjs.com/package/@democratize-quality/mcp-server) for the exact `--agents` or other flags.
- **`env.OUTPUT_DIR`**: Directory where the MCP server writes test plans and reports (e.g. `./api-test-reports`).

**Example with an optional `--agents` flag** (if your package version supports it):

```json
"args": [
  "@democratize-quality/mcp-server@latest",
  "--agents"
]
```

Confirm the exact flag name and behavior in the package docs.

### 2.2 `settings.json` (optional)

If you need to reference or drive MCP-related behavior from VS Code/Cursor **settings** (e.g. paths or env), you can add a snippet to `.vscode/settings.json`:

```json
{
  "democratizeQuality.outputDir": "./api-test-reports"
}
```

Note: The actual MCP server process is started from **`mcp.json`**; `settings.json` is only for any editor-specific or custom settings your team agrees on.

---

## 3. Workflow: Plan → Generate → Heal

1. **Plan**: Use **api_planner** with the service’s OpenAPI/Swagger URL (or local schema path) and base URL. Save the generated test plan (e.g. under `api-test-reports/` or into this doc).
2. **Generate**: Use **api_generator** (after **api_project_setup** if needed) to generate executable tests from the test plan.
3. **Heal**: Use **api_healer** on failing tests to fix assertions, endpoints, or data.
